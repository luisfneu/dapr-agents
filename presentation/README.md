# Presentation: Dapr Agents in 5 minutes

Everything needed to present from another machine.

| File | Use |
|---|---|
| `dapr-agents-in-5-minutes.pptx` | The deck (8 slides, 16:9, speaker notes with timings inside) |
| `dapr-agents-in-5-minutes.pdf` | Same deck, for a machine without PowerPoint |
| `demo.mp4` | 65s terminal recording of the demo; play it on slide 7 |
| `SPEAKER-NOTES.md` | The speaker notes as plain text, with [mm:ss] timing per slide |
| `build-pptx.js` | Generator (pptxgenjs); rebuild with `node build-pptx.js out.pptx` after `npm i pptxgenjs` |

Placeholders to fill before presenting: `[Your name]`, `[Event / team]` (slide 1), `[your contact]` (slide 8).

Run order: slides 1–6 (about 4:00), play `demo.mp4` on slide 7 (1:05), slide 8 to close.
