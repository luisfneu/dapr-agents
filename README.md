# Dapr Agents in 5 minutes

A short talk about [Dapr Agents](https://github.com/dapr/dapr-agents): what it is, what it is for,
and a demo of a durable agent that survives being killed mid-execution.

| Folder | Contents |
|---|---|
| [`demo/`](demo/) | Runnable demo: durable order-support agent, Dapr components, helper scripts, recorded video |
| [`presentation/`](presentation/) | The deck (PPTX + PDF), speaker notes and the demo video |

Stack: dapr-agents 1.1, Dapr 1.19, Python 3.13, Ollama (qwen3:4b) running locally.
